# TsigkouNav

Πόσο μακριά είναι και πόσο κοστίζει; Μια απλή, σύγχρονη εφαρμογή για υπολογισμό **απόστασης, διαδρομής οδήγησης, καυσίμων και διοδίων** μεταξύ πολλαπλών σημείων, με dark mode και υποστήριξη για περισσότερες από δύο στάσεις.

## Λειτουργίες

- Αναζήτηση διεύθυνσης με autocomplete
- Απόσταση + διάρκεια διαδρομής οδήγησης
- Επιλογή αποφυγής διοδίων, όταν ο routing server επιστρέφει διαθέσιμη εναλλακτική χωρίς διόδια
- Πολλαπλά ενδιάμεσα σημεία (μέχρι 8 στάσεις), με reordering και ανάλυση ανά σκέλος
- **Κόστος καυσίμου**: χειροκίνητα πεδία για κατανάλωση (L/100km) και τιμή καυσίμου (€/L), με λογικά defaults
- **Διόδια ανά σταθμό** για αυτοκίνητο ή μηχανή, με δεδομένα από το [mydiodia.gr](https://mydiodia.gr/) (βλ. παρακάτω)
- Dark mode (αποθηκεύεται στο localStorage)
- Πλήρως responsive (mobile & desktop)

## Καύσιμα & Διόδια

Το κόστος καυσίμου υπολογίζεται με τον απλό τύπο `(χλμ / 100) × κατανάλωση × τιμή`, από τα πεδία που ορίζει ο χρήστης (`src/app/services/fuel.util.ts`).

Τα διόδια υπολογίζονται **ανά σταθμό**, με τη βάση του [mydiodia.gr](https://mydiodia.gr/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)): 212 σταθμοί (μετωπικοί, πλευρικοί, γέφυρα Ρίου-Αντιρρίου, σήραγγα Ακτίου) με συντεταγμένες και τιμές για μηχανή (κατηγορία 1) και αυτοκίνητο (κατηγορία 2). Τα δεδομένα βρίσκονται στο `src/app/data/toll-stations.ts` και ενημερώνονται με:

```bash
npm run update-tolls
```

Ο εντοπισμός (`src/app/services/toll.util.ts`) γίνεται πάνω στη γεωμετρία της διαδρομής από το OSRM:

- Ένας σταθμός μετράει αν η διαδρομή περνά κοντά του: ~2,5 χλμ για μετωπικούς, ~130 μ. για πλευρικούς (ράμπες).
- Σταθμοί που εξυπηρετούν μόνο το αντίθετο ρεύμα αγνοούνται.
- Η Αττική Οδός χρεώνεται μία φορά ανά διαδρομή.
- Πλευρικός σταθμός χρεώνεται μόνο εκεί που μπαίνεις ή βγαίνεις από τον αυτοκινητόδρομο, όχι όταν απλώς περνάς δίπλα από τον κόμβο.

**Οι τιμές και ο εντοπισμός των διοδίων είναι κατά προσέγγιση** και μπορεί να διαφέρουν από την πραγματική χρέωση, π.χ. όταν η διαδρομή του OSRM διαφέρει από αυτή που ακολουθείς ή όταν αλλάζουν οι τιμοκατάλογοι. Εκπτώσεις (e-Pass, κάρτες, επιστροφή εντός ωρών) δεν λαμβάνονται υπόψη.

## Εκκίνηση

Χρειάζεται Node.js 20+ (ιδανικά 22+).

```bash
npm install
npm start        # ισοδύναμο με `ng serve`
```

Άνοιξε το `http://localhost:4200/`.

## Build για production

```bash
npm run build
```

Τα αρχεία βγαίνουν στο `dist/tsigkou-nav/browser`. Είναι ένα καθαρά static site — μπορεί να φιλοξενηθεί οπουδήποτε (Netlify, Vercel, GitHub Pages, Nginx κ.λπ.), δεν χρειάζεται backend.

## Δομή project

```
src/app/
  models/stop.model.ts              // Stop, AddressSuggestion, RouteResult
  models/toll-station.model.ts      // TollStation
  data/toll-stations.ts             // σταθμοί διοδίων (αυτόματα από scripts/update-tolls.mjs)
  services/
    geocode.service.ts              // Nominatim search
    route.service.ts                // OSRM route calculation
    toll.util.ts                    // εντοπισμός σταθμών διοδίων στη διαδρομή
    fuel.util.ts                    // κόστος καυσίμου
    theme.service.ts                // dark/light mode
    format.util.ts                  // μορφοποίηση απόστασης/διάρκειας
  components/
    address-input/                  // πεδίο αναζήτησης με autocomplete
    map/                            // Leaflet wrapper (markers + πολυγραμμή διαδρομής)
  app.ts / app.html                 // κεντρικό layout & λογική στάσεων
```

## Σημειώσεις για production χρήση

Οι δημόσιοι servers (OSRM, Valhalla της FOSSGIS, Nominatim, OSM tiles) κάνουν μόνο για δοκιμές: δεν επιτρέπουν εμπορική χρήση ή μεγάλη κίνηση, και το Nominatim απαγορεύει το autocomplete. Για production, όλες οι ρυθμίσεις είναι στο `src/app/app.settings.ts`:

- **`GEOAPIFY_API_KEY`**: κλειδί από το [Geoapify](https://myprojects.geoapify.com/) (δωρεάν πλάνο 3.000 credits/ημέρα, επιτρέπει εμπορική χρήση). Με αυτό, διαδρομές, αναζήτηση και χάρτης πάνε στο Geoapify. Περιόρισε το κλειδί στο domain σου από το dashboard.
- **`ADSENSE_CLIENT` / `ADSENSE_SLOT`**: publisher ID και ad unit του Google AdSense. Όσο είναι κενά, δεν φορτώνεται τίποτα από τη Google.

Για το AdSense χρειάζονται ακόμα:

1. Δικό σου domain και έγκριση του site από το AdSense.
2. Αρχείο `public/ads.txt` με τη γραμμή `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0` (το δικό σου publisher ID).
3. Μήνυμα συγκατάθεσης GDPR: AdSense → Privacy & messaging → European regulations.
4. Η πολιτική απορρήτου είναι στο `public/privacy.html`: συμπλήρωσε email επικοινωνίας.

## Πιθανά επόμενα βήματα

- Drag & drop reorder στις στάσεις (τώρα γίνεται με βελάκια πάνω/κάτω)
